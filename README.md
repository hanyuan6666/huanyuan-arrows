# 一箭又一箭

一个使用 Python + Pygame 开发的箭头消除类益智小游戏。

## 一、项目简介

玩家需要观察棋盘上每个箭头的方向，并按照合理的顺序点击箭头。

当箭头前方没有其他箭头阻挡时，点击箭头后，它会向对应方向飞出棋盘。

如果箭头前方存在其他箭头，则当前箭头无法移动，并会产生一次错误。

玩家最多可以错误 3 次，超过限制后游戏失败。

将当前关卡中的所有箭头清除后，即可完成关卡。

本项目目前设计了 3 个游戏关卡，难度逐渐增加。

---

## 二、开发环境

- 操作系统：Windows
- 编程语言：Python 3.12
- 游戏框架：Pygame 2.6.1
- 开发工具：Visual Studio Code
